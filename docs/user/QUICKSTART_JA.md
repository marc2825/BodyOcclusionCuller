# UnderWhere 操作ガイド

衣装に覆われた身体の面を調べ、隠しても見えない面を候補として示す Blender Extension です。判定は検査したポーズでの有限個のサンプルに基づくもので、すべての状況での安全を保証するものではありません。

動作確認環境：Windows 版 Blender 5.2.3 LTS

## インストール

1. [GitHub Releases](https://github.com/marc2825/BodyOcclusionCuller/releases) から Extension の ZIP を入手します。
2. Blender の **Preferences → Get Extensions → Install from Disk** で ZIP を指定し、有効にします（ZIP は展開しません）。
3. 3D View で N キーを押し、**UnderWhere** タブを開きます。

Release に含まれる `underwhere_demo.blend` で、操作を試せます。Demo_Body が身体、Demo_Armor が衣装です。下のブロックは非表示の候補に、上のブロックは露出として残ります。

## パネルの構成

上から順に操作します。結果に関するパネルは、Analyze の後に表示されます。

| パネル | 内容 |
|---|---|
| 1 Inputs | Body・衣装・モードの指定 |
| 2 Inspection | 検査するポーズ、処理量、Preflight と Analyze。中に Materials と Advanced（閉じた状態）があります |
| 3 Results | 判定ごとの面数、出力で隠れる面数、注意事項 |
| 4 Review and Fix | 比較表示、問題箇所の確認、手動での修正、既存マスクの修復方針 |
| 5 Output | コピーの作成とレポートの書き出し |

一番上には現在の状態が表示されます。解析中はここに進捗と Cancel ボタンが出ます。

## 基本の流れ

1. Object Mode で衣装と Body を選択します。Body を最後に選んでアクティブにし、**Use Selection** を押します（パネルで個別に指定することもできます）。対象のオブジェクトは表示しておいてください。
2. モードを選びます。
   - **Generate Mask**：非表示の候補を新しく求めます。
   - **Audit Existing Mask**：既存のマスクを検査します。対象は、モディファイアの最後にある Vertex Group 方式の Mask モディファイア 1 つです（Smooth はオフ、ビューポートとレンダーの表示設定は同じにします）。
3. 検査するポーズを決めます。現在のフレームは常に検査します。**Current + Selected Frames** を選ぶと、フレーム番号をカンマ区切りで最大 32 個追加できます（例：`1,10,20`）。どのフレームでも見えない面だけが候補になり、どこか 1 つでも見えた面は Keep になります。
4. 処理量を Quick / Balanced / Detailed から選びます。これはサンプルの細かさで、安全性の段階ではありません。
5. **Preflight**（チェックマーク）で入力を確認し、**Analyze**（再生マーク）を押します。Preflight は解析を行わず、形状・モディファイア・素材・既存マスクに問題がないかだけを調べます。解析は **Cancel Analysis**、またはそのビューポート上で Esc を押すと中断できます。

## 結果の見方

| 表示 | 意味 |
|---|---|
| Candidate（緑） | 検査したすべての状態で隠れていた面。非表示の候補 |
| Keep（青） | 見えることを確認した面。残す |
| Review（黄） | 判断できなかった面。自動では隠さない |
| 赤 | 既存マスクが、見える面を隠している |
| 紫 | 既存マスクが、判断できなかった面を隠している |

- **Output hidden** は、実際にマスクを適用したときに隠れる面数です。Blender の出力と照合しています。
- Keep や Review と頂点を共有する面は残すので、粗いメッシュでは候補があっても削減数が 0 になることがあります。
- **Update Comparison** を押すと、Body の右側（+X 方向）に比較用のメッシュを表示します。色を見るには、ソリッド表示で Color を Material にするか、マテリアルプレビューを使います。表示は次から選べます。
  - **Classification**：上の表の色分け
  - **Before / After**：既存マスクと出力の違い。新たに隠れる面は緑、元に戻る面は青、隠れたままの面は濃い灰色
  - **Output**：出力後の見た目
  - **Unmasked**：何も隠さない状態

## 問題箇所の確認と修正

Review の面は、自動では隠しません。隠してよいものだけを、人が確認して Hide にします。

### 範囲を選んでまとめて修正する

1. **Update Comparison**（Classification）で色付きの比較メッシュを表示します。Review の面は黄色です。
2. **Fix faces** の **Select on** で、選ぶ場所を Comparison（比較メッシュ）か Body（元の Body）から選びます。
3. 選び方のボタンを押して、ビューポートでドラッグします。

   | ボタン | 選び方 |
   |---|---|
   | **Box** | 矩形で囲む |
   | **Lasso** | 自由な形で囲む（投げ縄） |
   | **Brush** | なぞって塗る。マウスホイールでブラシの大きさを変える |

   Shift を押しながらドラッグすると選択に追加、Ctrl を押しながらだと選択から外します。途中でボタンを切り替えても、それまでの選択は残ります。
4. **Keep / Hide / Clear** を押します。比較メッシュで選んだ面は、元の Body の同じ面に反映され、比較メッシュは描き直されます。

**Review faces only**（既定でオン）のときは、選んだ範囲のうち Review の面と既存マスクの問題の面にだけ適用します。大まかに広く囲んでも、見えると判定された面や候補の面は変わりません。**Hide** は確認画面が出ます。Ctrl+Z で元に戻せます。元の判定と警告は記録に残ります。

**Select in bulk** には、Review の面すべて、既存マスクの問題の面すべて、理由ごとの面をまとめて選ぶボタンがあります。

### 1 面ずつ確認する

- 問題一覧から面を選び、**Select** を押すと、Edit Mode でその面を選択して表示します。
- **Next** で次の問題箇所へ移り、**View Ray** でその面が見えた視線の位置とフレームへ移動します。
- 面の詳細には、理由ごとの対処の目安が表示されます。

### 理由ごとの対処

| 理由 | 対処 |
|---|---|
| 透明度・透過を確認できない、未対応のシェーダー | 本当に不透明なら、Materials で Opaque にして再解析する（面ごとに Hide するより確実） |
| 裏面カリングを信頼できない | カリングを切れるなら切って再解析。無理なら目視で判断 |
| 身体と衣装が交差、接触または奥行きが不明確 | 衣装の位置やウェイトを直す。突き抜けを隠すだけなら Hide |
| 遮蔽物の形状に未解決の問題、開口部のある Solidify | 表示された衣装のメッシュを直して再解析するか、目視で判断 |
| 検査密度不足 | 処理量を Detailed にして再解析 |

### 既存マスクの修復方針（Audit のみ）

見えることを確認した面（赤）は、どちらの方針でも元に戻します。違うのは、判断できなかった面（紫）の扱いです。

- **Restore exposed + undecided**（既定）：判断できなかった面も元に戻します。隠れたまま残るのは、候補と確認できた面だけです。
- **Restore exposed only**：判断できなかった面は、既存マスクのとおり隠したままにします。手作業で作ったマスクを尊重したいとき、たとえば素材を自動判定できない衣装で使います。隠したままにした面の数は、結果と Apply の確認画面に表示されます。

既存マスクが無効になっている、何も隠していない、すべての面を隠している（Invert の設定違いなど）場合は、Preflight と結果に警告が出ます。

## 出力

Object Mode に戻り、隠れる面数を確認してから出力します。どちらの方法でも、元の Body と既存のマスクは変更しません。

- **Apply to New Copy**：Mask モディファイアを付けたコピーを、元と同じ位置・コレクションに作ります。
- **Create Deleted Copy**：コピーから該当する頂点を削除します。シェイプキー、UV、ウェイト、Armature は残ります。

シェイプキーを持つメッシュでは、Mask モディファイアを適用（Apply）できません。VRChat 向けに FBX で書き出すときは、Create Deleted Copy で作ったコピーを使います。

1. 削除済みコピーと Armature（衣装も出力する場合はそのメッシュも）を選択します。元の Body や比較用メッシュは選ばないでください。
2. FBX エクスポートで **Selected Objects をオン**、**Apply Modifiers をオフ**にして書き出します。

コピーは元の Body と重なって作られるので、表示の切り替えはアウトライナーで行います。コピーをもう一度 Body に指定して再検査することもできます。

## 素材の扱い

自動で「光を通さない」と判断するのは、Principled BSDF が直接つながり、Alpha が 1、Transmission が 0 で固定され、裏面カリングも Volume/Displacement もない素材だけです。MToon やアルファ付きテクスチャの素材は Review になります。

不透明だと分かっている素材は、2 Inspection の中の **Materials** で **Opaque** をオンにできます。これは「素材全体が表裏とも不透明」というユーザーの仮定として扱い、レポートに記録します。

- テクスチャで穴を表現している素材には使わないでください。
- 裏面カリングが有効な素材には適用できません。
- 素材ごとの自動判定は、素材名の下に表示されます。

## 対応している構成

- Body と衣装の Armature 変形、シェイプキー
- 衣装の Solidify。開口部は厚み付け前の形で調べます。元の形に開口部がある場合、見えた面は Keep、それ以外は Review になり、自動では隠しません。
- 開口部が多すぎる、または非多様体の衣装は、オブジェクト名と理由を表示します。その衣装に遮られているだけの面は Review になります。
- Body の Solidify、Subdivision、Mirror、Geometry Nodes など、面の対応が変わる構成には対応していません。適用済みの作業用コピーを使ってください。
- Spatial step などの長さはメートルで指定します。シーンの Unit Scale で換算します。

## 判定についての注意

- 身体自身は遮蔽物として扱いません。隠した面の奥が見えてしまう事故を防ぐためです。そのため、背中の開いた衣装では、前面の身体も残ることがあります。
- 細い隙間、検査していないポーズやフレームの間、影・反射・AO・物理演算については保証しません。
- 大きなモデルでは、メッシュの取得や出力の照合で一時的に待たされることがあります。実アバターでの処理時間はまだ確認していません。

## レポートと再解析

- **Export Shareable Report** は、件数・理由・バージョン・処理時間だけを書き出します。座標、面のつながり、オブジェクト名や素材名、個人のパスは含みません。不具合報告にはこちらを使ってください。
- 書き出し画面の **Private full diagnostics** は形状データを含みます。手元での調査用で、公開しないでください。
- 解析結果は .blend ファイルに保存されません。ファイルを開き直したとき、Extension を再度有効にしたとき、入力を変更したときは、もう一度 Analyze を実行してください。入力が変わっている場合、出力や書き出しは拒否されます。
