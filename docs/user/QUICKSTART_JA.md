# UnderWhere 操作ガイド

衣装に覆われた身体の面を調べ、隠しても見えない面を候補として示す Blender Extension です。判定は検査したポーズでの有限個のサンプルに基づくもので、すべての状況での安全を保証するものではありません。

動作確認環境：Windows 版 Blender 5.2.3 LTS

## インストール

1. [GitHub Releases](https://github.com/marc2825/BodyOcclusionCuller/releases) から Extension の ZIP を入手します。
2. Blender の **Preferences → Get Extensions → Install from Disk** で ZIP を指定し、有効にします（ZIP は展開しません）。
3. 3D View で N キーを押し、**UnderWhere** タブを開きます。

画面の言葉は、Blender の言語設定に合わせて日本語か英語で表示されます。このガイドでは、日本語の名前の後に英語の名前を括弧で添えています。

Release に含まれる `underwhere_demo.blend` で、操作を試せます。Demo_Body が素体、Demo_Armor が衣装です。

## 画面の構成

一番上に、今の状態と次にやることが表示されます。調べている間は進み具合と「中止」（Cancel）、エラーのときは直し方とエラーのコードが出ます。

その下の切り替えで、3 つの段階を行き来します。調べ終わると、自動で「確認」に進みます。

| 段階 | 内容 |
|---|---|
| 準備（Set up） | 素体と衣装を選び、細かさを決めて調べる |
| 確認（Review） | 結果と「次にやること」を見て、要確認の面を決める |
| 書き出し（Export） | 出力用のコピーを作る |

## 1. 準備（Set up）

1. Object Mode で衣装を選び、最後に素体を選んでアクティブにします。「選択から設定」（Use selection）を押すと、素体と衣装が設定されます。パネルで個別に指定することもできます。対象のオブジェクトは表示しておいてください。
   - 頭と胴体など、素体が複数のオブジェクトに分かれている場合は、「素体が複数のオブジェクトに分かれている」（Body has several objects）をオンにします。残りのオブジェクトを選んでリストの **+** を押します。素体どうしは互いを隠すものとして扱わず、隠すのは衣装だけです。
2. 「細かさ」（Detail）を「速い」「標準」「細かい」（Fast / Standard / Fine）から選びます。これはサンプルの細かさで、安全性の段階ではありません。
3. 「調べる」（Analyze）を押します。このビューの上で Esc を押すか、「中止」で止められます。

「入力チェックだけ行う」（Check inputs only）は、調べる前に形状・モディファイア・素材・既存マスクに問題がないかだけを確認し、素体の大きさを表示します。

折りたたまれた欄に、ほかの設定があります。

- **ポーズと目的**（Poses and purpose）
  - 「現在のポーズと指定したフレーム」を選ぶと、フレーム番号をカンマ区切りで最大 32 個追加できます（例：`1, 10, 20`）。現在のフレームは常に調べます。すべてのフレームで隠れている面だけが「隠せる」になり、1 つでも見えた面は「見える」になります。
  - 目的は「隠せる面を探す」か「既存のマスクを検査する」です。検査できるのは、モディファイアの一番下にある頂点グループ方式の Mask モディファイア 1 つです（Smooth はオフ、ビューポートとレンダーの表示設定はそろえます）。
- **衣装の素材**（Clothing materials）：素材ごとの自動判定と「不透明」（Opaque）の切り替え。詳しくは「素材の扱い」を見てください。
- **サンプリングの数値**（Sampling values）：サンプルの間隔などの数値。

## 2. 確認（Review）

### 結果と次にやること

「結果」（Result）には、削除できる面の数と割合、判定ごとの面の数が表示されます。

| 判定 | 色 | 意味 |
|---|---|---|
| 隠せる（Hideable） | 緑 | 調べたすべての状態で隠れていた面 |
| 見える（Visible） | 青 | 見えることを確認した面。残す |
| 要確認（Unsure） | 黄 | 判断できなかった面。自動では隠さない |
| マスクが見える面を隠す | 赤 | 既存マスクが、見える面を隠している（検査のときだけ） |
| マスクが要確認の面を隠す | 紫 | 既存マスクが、要確認の面を隠している（検査のときだけ） |
| 自分で隠した | ピンク | 自分で「隠す」にした面 |
| 自分で残した | 白 | 自分で「残す」にした面 |

「次にやること」（Next steps）には、まだ人の判断が必要なことが、重要な順に並びます。

- 注意（三角のアイコン）：書き出す前に確かめたいこと。たとえば、自分で隠した面が「見える」と判定されている場合です。
- 決めること（？のアイコン）：素材が原因の要確認の面（その場で「不透明」を切り替えて調べ直せます）や、残っている要確認の面（その場で選び始められます）。
- 情報：頂点の共有で残る面の数など。対応は不要です。

決めることがなくなると、「書き出しへ進む」が表示されます。

削除できる面の数は、実際にマスクを適用したときに隠れる面の数で、Blender の出力と照合しています。「見える」「要確認」の面と頂点を共有する面は残すので、粗いメッシュでは「隠せる」面があっても削除数が 0 になることがあります。

### 比較メッシュ

調べ終わると、素体の右側（+X 方向）に色分けした比較メッシュが表示されます。色が見えないときは、「このビューで色を表示する」（Show colours in this view）を押します。

表示は次から選べます。表示を変えたら「更新」（Update）を押します。

- **判定**（Verdicts）：上の表の色分け。凡例の色を押すと、その色の面を表示するかどうかを切り替えられます（例：要確認だけを表示して選ぶ）。
- **既存マスクとの差**（Before / After）：新たに隠れる面は緑、再び表示される面は青、隠れたままの面は濃い灰色。
- **出力後**（After output）、**マスクなし**（Without mask）。
- **ポーズ別**（Poses）：複数のフレームを調べたとき、各面が何割のフレームで隠れていたか。すべてで隠れていた面は緑、75% 以上は黄、50% 以上は橙、それ未満は赤、一度も隠れなかった面は青、どのフレームでも判断できなかった面は灰色です。判定そのものは変わらず、1 つのフレームでも見えた面は残します。

### 範囲を選んで決める

要確認の面は、自動では隠しません。隠してよいものだけを、人が確認して「隠す」にします。

1. 「面を選ぶ」（Choose faces）で、選ぶ場所を「比較メッシュ」（Comparison、既定）か「素体」（Body）から選びます。
2. 「囲む」「投げ縄」「なぞる」（Box / Lasso / Brush）のどれかを押します。面を選べる状態（Edit Mode）になります。

   | ボタン | 選び方 |
   |---|---|
   | 囲む（Box） | 四角形で囲む |
   | 投げ縄（Lasso） | 自由な形で囲む |
   | なぞる（Brush） | なぞって塗る。マウスホイールでブラシの大きさを変える |

3. ビューポートで左ドラッグします。Shift を押しながらだと追加、Ctrl を押しながらだと除外です。途中でボタンを切り替えても、それまでの選択は残ります。選んだ面の数はパネルに表示されます。
4. 「決める」（Decide）で「残す」「隠す」「取り消す」（Keep / Hide / Clear choice）を押します。比較メッシュで選んだ面は、素体の同じ面に反映されます。比較メッシュは描き直され、そのまま次の範囲を選べます。
5. 終わったら「完了」（Done）を押して Object Mode に戻ります。

「要確認の面だけ変える」（Only change unsure faces、既定でオン）のときは、選んだ範囲のうち要確認の面と、既存マスクの問題の面にだけ適用します。大まかに広く囲んでも、判定済みの面は変わりません。範囲に該当する面がないときは、選択を残したまま知らせるので、チェックを外してもう一度押せます。

「隠す」は確認画面が出ます。どの操作も Ctrl+Z で元に戻せ、元の判定は記録に残ります。比較メッシュは表示用です。面を削除・追加すると「残す」「隠す」を受け付けないので、「更新」を押してください。

### 理由ごとに選ぶ・1 面ずつ見る

- **理由ごとに選ぶ**（Select by reason、折りたたみ）：同じ理由の要確認の面を、素体の上でまとめて選びます。理由ごとの対処の目安も表示します。
- **1 面ずつ見る**（One face at a time、折りたたみ）：一覧から面を選んで「選ぶ」（Select）を押すと、その面を選択して表示します。「次へ」（Next）で次の要確認の面へ、「光線から見る」（View ray）でその面が見えた視線の位置とフレームへ移動します。

### 理由ごとの対処

| 理由 | 対処 |
|---|---|
| 素材が透けるかもしれない、未対応のシェーダー | 本当に不透明なら「不透明」にして調べ直す（面ごとに隠すより確実） |
| 裏面カリングが有効 | カリングを切れるなら切って調べ直す。無理なら目で見て決める |
| 素体と衣装が交差、衣装に接している | 衣装の位置やウェイトを直す。突き抜けを隠すだけなら「隠す」 |
| 衣装の形を判定しきれない、厚みを付けた衣装の開口部 | 表示された衣装のメッシュを直して調べ直すか、目で見て決める |
| サンプルが粗い | 細かさを「細かい」にして調べ直す。全面がこれなら素体の大きさを確認する |

### 既存マスクの修復方針（検査のときだけ）

見えることを確認した面（赤）は、どちらの方針でも再表示します。違うのは、要確認の面（紫）の扱いです。

- 「見える面と要確認の面を再表示」（既定）：隠れたまま残るのは、隠れていると確認できた面だけです。
- 「見える面だけを再表示」：要確認の面は、既存マスクのとおり隠したままにします。手作業で作ったマスクを尊重したいときに使います。隠したままにした面の数は、「次にやること」と出力の確認画面に表示されます。

既存マスクが無効、何も隠していない、すべての面を隠している（Invert の設定違いなど）場合は、入力チェックと結果に表示されます。

## 3. 書き出し（Export）

どちらの方法でも、元の素体と既存のマスクは変更しません。コピーは元の素体と同じ位置・コレクションに作ります。素体が複数のオブジェクトに分かれている場合は、オブジェクトごとに作ります。

- **マスクで隠したコピーを作る**（Create masked copy）：Mask モディファイアで面を隠します。元に戻しやすい方法です。
- **面を削除したコピーを作る**（Create copy with faces removed）：面を削除し、シェイプキー・UV・ウェイト・Armature は残します。

シェイプキーを持つメッシュでは、Mask モディファイアを適用できません。VRChat 向けに FBX で書き出すときは、面を削除したコピーを使います。

1. 作成後に表示される「コピーを選択」（Select the copy）を押し、Armature も選びます（衣装も出力する場合はそのメッシュも）。元の素体や比較メッシュは選ばないでください。
2. FBX エクスポートで **Selected Objects をオン**、**Apply Modifiers をオフ**にして書き出します。

「次にやること」に注意が残っている場合は、書き出しの段階にも表示されます。

## 素材の扱い

自動で「不透明」と判断するのは、Principled BSDF が直接つながり、Alpha が 1、Transmission が 0 で固定され、裏面カリングも Volume/Displacement もない素材だけです。MToon やアルファ付きテクスチャの素材は要確認になります。

不透明だと分かっている素材は、「衣装の素材」の欄か「次にやること」で「不透明」（Opaque）をオンにできます。これは「素材全体が表裏とも不透明」というあなた自身の判断として扱い、レポートに記録します。

- テクスチャで穴を表現している素材には使わないでください。
- 裏面カリングが有効な素材には使えません。
- 実際にアニメーションしている素材（中身のあるアクション・ドライバー・NLA）は判定に使いません。中身が空のアニメーション情報だけなら問題ありません。

## 対応している構成

- 素体と衣装の Armature 変形、シェイプキー
- 複数のオブジェクトに分かれた素体（隠せる面を探すときのみ。既存マスクの検査は 1 つずつ行います）
- 衣装の Solidify。開口部は厚み付け前の形で調べます。元の形に開口部がある場合、見えた面は「見える」、それ以外は要確認になり、自動では隠しません。
- 開口部が多すぎる、または非多様体の衣装は、オブジェクト名と理由を「次にやること」に表示します。その衣装に遮られているだけの面は要確認になります。
- 素体の Solidify、Subdivision、Mirror、Geometry Nodes など、面の対応が変わる構成には対応していません。適用済みの作業用コピーを使ってください。
- サンプルの間隔などの長さはメートルで指定します。シーンの Unit Scale で換算します。
- ワールドで 10 m を超える素体は単位の取り違えとみなし、10 の累乗で縮めた大きさで調べます。素体の大きさは入力チェックと結果に表示されます。
- オブジェクトのスケールが極端に小さくても（FBX の 0.0001 など）、ワールドで正しい大きさなら調べられます。

## 判定についての注意

- 素体自身は、衣装の代わりに面を隠すものとして扱いません。隠した面の奥が見えてしまう事故を防ぐためです。そのため、背中の開いた衣装では、前面の身体も残ることがあります。
- 細い隙間、調べていないポーズやフレームの間、影・反射・AO・物理演算については保証しません。
- 大きなモデルでは、メッシュの取得や出力の照合で一時的に待たされることがあります。

## 結果の保存と調べ直し

- 結果は .blend ファイルに保存されません。ファイルを開き直したとき、アドオンを有効にし直したとき、入力を変えたときは、もう一度「調べる」を押してください。結果が古くなると、上部に理由と「調べ直す」（Analyze again）が表示され、古い結果での出力はできません。
- 「残す」「隠す」の指定は .blend ファイルに保存されます。調べ直したとき、素体の面の構成が変わっていなければ自動で引き継ぎ、「結果」に引き継いだ件数を表示します。不要なら「消す」（Clear）ですべての指定を消せます。

## レポート

- 「共有用レポートを書き出す」（Export shareable report）は、件数・理由・バージョン・処理時間だけを書き出します。座標、面のつながり、オブジェクト名や素材名、個人のパスは含みません。不具合の報告にはこちらを使ってください。
- 書き出し画面の「完全な診断データを含める」は形状データを含みます。手元での調査用で、公開しないでください。
